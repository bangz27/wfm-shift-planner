# WFM Shift Planner (จัดกะ WFM)

เว็บแอปไฟล์เดียวสำหรับวางแผนกะทำงานและวันหยุดของพนักงานฮับ (Ops) และคนขับ (Driver) แล้วส่งออกเป็นไฟล์ **Upload Planned HC** (แท็บ Dedicated) สำหรับอัปโหลดเข้า FMS › Event Roster Planning

## ความสามารถ
- เก็บรายชื่อพนักงาน: Driver ID / Ops ID, Employee ID, ชื่อ, Function / Department, กะ, วันหยุดประจำสัปดาห์, วันหยุดชดเชย 1–3, วันเริ่มงาน, สถานะ (ทำงานอยู่ / ลาออก + วันที่ลาออก)
- นำเข้ารายชื่อจาก Template ที่ดาวน์โหลดจาก FMS (ดึงกะ วันหยุด และวันหยุดพิเศษให้อัตโนมัติ)
- วางจาก Excel ได้ โดยคอลัมน์แรกเป็นรหัส ส่วนคอลัมน์อื่นเรียงแบบไหนก็ได้
- ตารางรายเดือน กดแก้รายวันได้ และมีจำนวนคนทำงานต่อวัน
- ส่งออกโดยเขียนลง Template ที่แนบมา ส่วนอื่นของไฟล์ไม่ถูกแก้ ส่วนคนลาออกจะส่งเป็นช่องว่างเพื่อลบกะ
- ซิงก์ข้อมูลข้ามเครื่องผ่าน Supabase (ไม่บังคับ) ถ้าไม่ตั้งค่า ข้อมูลจะเก็บในเบราว์เซอร์

> ไฟล์ในโปรเจกต์นี้ไม่มีข้อมูลพนักงานหรือข้อมูลจากระบบติดมา ข้อมูลทั้งหมดอยู่ใน Supabase ของผู้ใช้เอง (ป้องกันด้วย RLS) หรืออยู่ในเบราว์เซอร์

## Supabase
แอปตั้งค่าเชื่อมโปรเจกต์ `wfm-shift-planner` ไว้แล้ว (`SB_DEFAULT` ใน `index.html`) ใช้ได้ทันทีโดยสมัครบัญชีในแอป

### ถ้าจะย้ายไปใช้โปรเจกต์อื่น
1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) (แพ็กเกจฟรีก็ใช้ได้)
2. ไปที่ **SQL Editor** วางเนื้อหาไฟล์ [`supabase/schema.sql`](supabase/schema.sql) แล้วกด Run
3. ไปที่ **Project Settings › API** คัดลอก **Project URL** และ **Publishable key** (หรือ anon key)
4. เปิดแอป ไปที่แท็บ **ตั้งค่า › Supabase** วางค่า URL กับ key แล้วกด "บันทึกและเชื่อมต่อ"
5. สมัครบัญชีด้วยอีเมลและรหัสผ่าน (Supabase จะส่งอีเมลให้ยืนยัน) แล้วเข้าสู่ระบบ
6. ถ้าเคยมีข้อมูลในเครื่องอยู่แล้ว ให้กด "อัปโหลดข้อมูลในเครื่องขึ้น Supabase"

publishable key เปิดเผยได้ เพราะตาราง `wfm_planner` เปิด Row Level Security แต่ละบัญชีจึงอ่านและเขียนได้เฉพาะข้อมูลของตัวเอง ส่วนคนที่ไม่ได้ล็อกอินเข้าถึงไม่ได้

ถ้าไม่อยากต้องกรอกค่าทุกเครื่อง ให้ใส่ค่าไว้ใน `SB_DEFAULT` ที่ด้านบนของสคริปต์ใน `index.html`

## ใช้กับหลายฮับ
- Sup ของแต่ละฮับสมัครบัญชีของตัวเอง ข้อมูลแยกกันตามบัญชี (RLS)
- นำเข้า Template ของฮับตัวเอง แอปจะตั้ง Station Name จากไฟล์ให้อัตโนมัติ
- สมัครได้เฉพาะอีเมล `@spxexpress.com` / `@shopee.com` ถ้าต้องการอนุญาตอีเมลอื่นเป็นรายคน ให้เพิ่มในตาราง `wfm_signup_allowlist`

## วิธีใช้งานรายเดือน
1. ที่ FMS › Event Roster Planning เลือกแท็บ **Drivers** หรือ **Operators** › Batch Action › Upload Planned HC › Download Template แล้วเลือก Next Month
2. ในแอป ไปที่แท็บพนักงาน › **นำเข้าจากไฟล์ FMS** เพื่ออัปเดตรายชื่อ
3. แก้เฉพาะคนที่เปลี่ยน แล้วไปที่แท็บ **ส่งออกไฟล์** › แนบ Template เดิม › ตรวจตาราง › ส่งออก
4. อัปโหลดไฟล์ที่ได้ **ในแท็บเดียวกับที่ดาวน์โหลดมา** แล้วตรวจผลการตรวจไฟล์ของระบบก่อนกด Submit

| Error จาก FMS | สาเหตุ |
|---|---|
| `181403009 Invalid excel template` | อัปโหลดผิดแท็บ (ไฟล์ Ops อยู่ในหน้า Drivers หรือกลับกัน) |
| `181403016 Template should only contain this month / next month shift` | วันที่ในหัวตารางไม่ใช่เดือนนี้หรือเดือนหน้า |

## ค่าที่ใช้ในระบบ
- วันหยุดใช้ `RD` ถ้าวันเดียวกันมีทั้งวันหยุดและกะ ให้คั่นด้วยเครื่องหมายจุลภาค
- Ops ID ต้องมี `Ops` นำหน้า เช่น `Ops1234` (แอปเติมให้อัตโนมัติ)
- Function ของคนขับ เช่น `Pickup+Delivery`, `LH`
- กะ เช่น `0700-1600`, `0900-1800`
